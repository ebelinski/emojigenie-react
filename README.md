# EmojiGenie 🧞‍♀️

[EmojiGenie](https://emojigenie.com) is a tool to find emojis quickly and copy them to your clipboard. It is a [CRA](https://github.com/facebookincubator/create-react-app) app.

## Development

1. Install [Yarn](https://yarnpkg.com/)
2. `yarn install`
3. `yarn start`

## Deploy

Pushing to `main` builds the site and deploys it to GitHub Pages ([`.github/workflows/pages.yml`](.github/workflows/pages.yml)).
